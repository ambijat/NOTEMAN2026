Built for careful inquiry

Structure without friction

The capture loop stays lightweight while the underlying note remains traceable, portable, and ready for later review.

01 / Provenance

Source-aware fragments

Each fragment carries its source, locator, capture method, and creation time instead of burying context in a loose paragraph.

02 / Retrieval

Retrieve existing notes

Bring an exported note back into the working area, inspect the latest capture, and continue deliberately.

03 / AI boundary

Inspectable prompt workbench

Copy prompts to any model, paste results back as drafts, and keep human review between generation and acceptance.

04 / Portability

Markdown plus metadata

Your notes stay readable outside the app while JSON sidecars preserve the structured research record.

05 / Safety

No silent loss

Captured material must contain text or point to a recoverable asset. Export transitions remain explicit and visible.

06 / Independence

Local and vendor-neutral

The core workflow depends on local files and the clipboard—not on a single cloud, model provider, or proprietary format.
