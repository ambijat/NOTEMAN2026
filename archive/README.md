# Historical archive

This directory preserves NoteMan lineage and is not an active implementation.

- `legacy-noteman/` retains the imported Git history and final contents of the
  former `ambijat/NOTEMAN` repository.
- `workspace-snapshot/` retains standalone scripts and binaries found in the
  pre-consolidation `NOTEMAN2026` workspace. Some versions differ from files in
  `legacy-noteman/`, so they are intentionally preserved rather than deduplicated.

New product development belongs in `apps/ubuntu-python/` or
`apps/windows-dotnet/`.
